# CSE3 XOR Encoder Decoder

Use XOR to encode and decode a byte stream while explaining why the same
operation reverses itself.

## Goals

- build confidence with XOR at the byte level
- compare input, encoded, and decoded byte views
- explain why XOR is useful for toggling bits and reversible transforms

## Starter Expectations

- allow a custom key
- explain each output line in a short writeup
- add a per-byte trace if the student wants a deeper challenge

## Solution Highlights

- accepts a custom one-byte key
- prints clear byte dumps for input and output
- demonstrates the reversible property of XOR
