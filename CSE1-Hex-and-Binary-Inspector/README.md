# CSE1 Hex and Binary Inspector

Build a small inspector that shows the same numeric value in decimal,
hexadecimal, and binary.

## Goals

- practice decimal, binary, and hex conversion
- connect bytes and nibbles to visible output
- compare signed and unsigned interpretations of the same bits

## Starter Expectations

- add more signedness commentary
- explain what each nibble means
- extend the inspector with one additional representation or check

## Solution Highlights

- prints grouped binary output
- shows both unsigned and signed 16-bit interpretations
- breaks the value into high and low bytes
